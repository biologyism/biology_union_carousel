قدم صفر: آپدیت ربات (فقط ۴ کلیک)

ربات قبلی آلبوم می‌ساخت. نسخه جدید رو باید جایگزین کنی:

  1. فایل bot.py رو از همین‌جا دانلود کن
  2. برو به ریپوی گیت‌هابت: biologyism/biology_union_carousel
  3. روی Add file ← Upload files بزن
  4. فایل bot.py جدید رو بکش و بنداز داخل صفحه (فایل قبلی خودکار جایگزین می‌شه)
  5. دکمه سبز Commit changes رو بزن
💡 بعد از Commit، ربات خودش با کد جدید روشن می‌شه (چون ورک‌فلو روی هر تغییر اجرا می‌شه). فقط ۱ دقیقه صبر کن.
⚠️ فایل رو bot.py با همون اسم آپلود کن، وگرنه ورک‌فلو پیداش نمی‌کنه.
▶

چطور استفاده کنم؟

  1. توی چت با ربات (یا توی گروه) بنویس: /start
  2. عکس‌هاش رو یکی‌یکی بفرست (تا ۱۰ تا) 📸
  3. روی «🎬 ساخت کاروسل» بزن
  4. حالا با ◀️ ▶️ بین اسلایدها بچرخ 🎉

بعد از ساخت، این دکمه‌ها رو داری:

  • ✏️ کپشن این اسلاید — متن روی همین عکس رو عوض می‌کنه
  • ➕ عکس — اسلاید جدید اضافه می‌کنه
  • ➖ حذف این اسلاید — اسلایدی که روش هستی رو برمی‌داره
  • 📤 انتشار — کاروسل رو به کانال/گروه مقصد می‌فرسته، بدون اینکه نامت دیده بشه
  • 🗑 پاک کردن — کل کاروسل رو حذف می‌کنه
👥

توی گروه — همه بتونن استفاده کنن

۳ کار لازمه:

الف) خاموش کردن Group Privacy:

  1. برو به @BotFather
  2. /mybots → رباتت رو انتخاب کن
  3. Bot Settings ← Group Privacy ← Turn off
⚠️ اگه این کار رو نکنی، ربات عکس‌هایی که بقیه توی گروه می‌فرستن رو نمی‌بینه.

ب) اضافه کردن ربات به گروه:

  1. تنظیمات گروه ← اعضا ← افزودن عضو ← یوزرنیم ربات
  2. ربات رو ادمین کن

ج) تست: توی گروه /start بزن و چند عکس بفرست.

👥 هر عضو گروه /start می‌زنه و کاروسل خودش رو می‌سازه. همه کاروسل‌های ساخته‌شده رو می‌تونن ورق بزنن.
📤

انتشار در کانال (بدون نام من)

  1. وقتی کاروسل آماده شد، دکمه «📤 انتشار» رو بزن
  2. یوزرنیم کانال رو بفرست: @mychannel
    یا آیدی عددی: -1001234567890
  3. تمام! کاروسل توی کانال می‌ره و مردم با ◀ ▶ ورقش می‌زنن
⚠️ ربات باید در کانال/گروه مقصد ادمین باشه، وگرنه ارسال ناموفق می‌شه.
💡 فقط یوزرنیم کانال‌های عمومی کار می‌کنه. برای کانال خصوصی باید آیدی عددی (-100...) بدی.

مشکلات رایج

دکمه‌ها کار نمی‌کنن / می‌گه «کاروسل منقضی شده»

ربات روی گیت‌هاب هر چند ساعت یک‌بار ری‌استارت می‌شه و کاروسل‌های قبلی از حافظه پاک می‌شن. کافیه عکس‌ها رو دوباره بفرستی و یکی جدید بسازی. خود عکس‌ها و کپشن‌ها همیشه توی تلگرام می‌مونن — پیام ساخته‌شده پاک نمی‌شه.

عکس عوض می‌شه ولی پیام جدید هم میاد

این‌طبیعیه: پیام‌های «✅ ذخیره شد» جدا فرستاده می‌شن. فقط خودِ کاروسل در یک پیام می‌مونه.

کپشن نمی‌شینه

مطمئن شو بعد از زدن «✏️ کپشن این اسلاید» متن رو به‌صورت پیام فرستادی. کپشن هر اسلاید جداست.

توی گروه جواب نمی‌ده

۹۰٪ مواقع Group Privacy خاموش نشده. بعد از خاموش کردن، ربات رو از گروه حذف و دوباره اضافه کن.

Actions قرمز شد ❌

توکن اشتباهه. Settings ← Secrets and variables ← Actions ← BOT_TOKEN رو درست کن.
