۸ قدم — هر قدم رو انجام بده، آخرش ربات کار می‌کنه

۰

چی داری و چی لازم داری

فقط یک فایل لازم داری: carousel-bot-final.zip

و یک چیز دیگه: باید از قبل یک ربات در تلگرام ساخته باشی و توکنش رو داشته باشی (قدم ۴ توضیح می‌ده).

ربات چی می‌سازه؟ یک کاروسل نیتیو تلگرام — فلش‌ها و نقطه‌ها رو خودِ تلگرام می‌سازه:

این قابلیت از کجا می‌آد؟

تلگرام از تابستان ۲۰۲۶ قابلیت Rich Messages رو اضافه کرده که یک بلوک به اسم slideshow داره — یعنی اسلایدشوی نیتیو داخل پیام.

  • فلش‌های ◀ ▶ و نقطه‌های پایین رو خود تلگرام می‌کشه — نه ربات
  • با انگشت (گوشی) یا موس (کامپیوتر) ورق می‌خوره
  • توی کانال هم همین‌طوری نشون داده می‌شه
  • ربات با متد sendRichMessage اون رو می‌فرسته
نکته: اگه گوشی یا تلگرام یکی از اعضا قدیمی باشه و این قابلیت رو نشون نده، ربات خودکار به حالت دکمه‌ای (◀ ⚙️ ▶) برمی‌گرده تا همیشه کار کنه.
۱

فایل zip رو باز کن

  1. فایل carousel-bot-final.zip رو دانلود کن
  2. راست‌کلیک → Extract All → Extract
  3. حالا یک پوشه داری که ۱۰ فایل توش هست
درست شد اگه: داخل پوشه فایل‌هایی مثل bot.py، START-HERE.txt و یک پوشه به اسم .github می‌بینی.
پوشه .github رو نمی‌بینی؟ توی فولدر ویندوز برو: View ← Hidden items رو تیک بزن.
۲

همه فایل‌ها رو روی گیت‌هاب آپلود کن

  1. برو به ریپوت:github.com/biologyism/biology_union_carousel
  2. دکمه Add file (بالای صفحه) → Upload files
  3. داخل پوشه‌ای که Extract کردی برو و Ctrl + A بزن (همه انتخاب بشن)
  4. همه رو با موس بکش و بنداز توی صفحه گیت‌هاب
  5. صبر کن آپلود تموم بشه، بعد پایین صفحه Commit changes رو بزن
درست شد اگه: بعد از Commit، فایل‌های bot.py و START-HERE.txt رو توی لیست فایل‌های ریپو می‌بینی.
💡 فایل‌های هم‌نام خودشون جایگزین می‌شن — لازم نیست اول پاکشون کنی.
۳

به گیت‌هاب اجازه بده ذخیره کنه

بدون این قدم، ربات کار می‌کنه ولی کاروسل‌های قبلی بعد از چند ساعت از کار می‌افتن.

  1. بالای ریپو: Settings
  2. منوی سمت چپ: Actions → General
  3. برو پایین صفحه تا بخش Workflow permissions
  4. گزینه Read and write permissions رو انتخاب کن
  5. دکمه Save
درست شد اگه: دایره‌ی کنار «Read and write permissions» پر شده و Save رو زدی.
۴

توکن ربات رو بذار

اگه قبلاً این کار رو کردی، این قدم رو رد کن.

اول توکن رو بگیر:

  1. تلگرام → @BotFather → /newbot
  2. اسم و یوزرنیم (آخره یوزرنیم باید bot باشه)
  3. یک متن مثل 123456:AAE... می‌ده = توکن

حالا بذارش توی گیت‌هاب:

  1. Settings → Secrets and variables → Actions
  2. New repository secret
  3. Name: BOT_TOKEN
  4. Secret: توکنی که کپی کردی
  5. Add secret
توکن رو به هیچ‌کس نده. مثل رمز عبور رباته.
۵

ربات رو روشن کن

  1. بالای ریپو: تب Actions
  2. اگه پیامی اومد، I understand my workflows, go ahead رو بزن
  3. از سمت چپ Run Carousel Bot رو انتخاب کن
  4. دکمه Run workflow (سمت راست) → دوباره Run workflow سبز
  5. ۱ تا ۲ دقیقه صبر کن
درست شد اگه: کنار اجرا یک تیک سبز ✅ می‌بینی. اگه زرد (در حال اجرا) بود یعنی هنوز داره بالا میاد.
قرمز ❌ شد؟ یعنی توکن اشتباهه — برگرد به قدم ۴.

⚠️ خیلی مهم — فقط یک اجرا باید فعال باشه:

اگه توی لیست Actions چند تا زرد (In progress) دیدی، یعنی چند نسخه از ربات همزمان روشن شدن و با هم دعوا می‌کنن. باید همه رو به‌جز آخری لغو کنی:

  1. روی هر اجرای قدیمی کلیک کن
  2. بالا سمت راست: Cancel workflow
  3. این کار رو برای همه‌ی اجراهای قدیمی تکرار کن
  4. فقط جدیدترین اجرا بمونه
چرا؟ هر اجرای اضافه هم سهمیه‌ی گیت‌هابت رو مصرف می‌کنه، هم باعث می‌شه ربات قطع و وصل بشه.
۶

تست کن

  1. توی تلگرام برو به رباتت (یوزرنیمش رو سرچ کن)
  2. بفرست: /start
  3. چند عکس بفرست — یکی‌یکی
  4. دکمه «🎬 ساخت کاروسل» رو بزن
  5. با انگشت یا فلش‌های روی عکس ورق بزن 🎉
💡 عکس‌ها رو آلبومی نفرست. توی آلبوم تلگرام فقط عکس اول به ربات می‌رسه.
درست شد اگه: یک کاروسل دیدی که با فلش‌های ◀ ▶ روی لبه‌ها و نقطه‌های پایین ورق می‌خوره — دقیقاً همون نمونه‌ای که می‌خواستی.
۷

ربات رو به گروه اضافه کن

تا همه‌ی اعضای گروه بتونن استفاده کنن، ۳ کار:

الف) حریم خصوصی رو خاموش کن:

  1. تلگرام → @BotFather → بفرست /mybots
  2. رباتت رو انتخاب کن
  3. Bot Settings → Group Privacy
  4. Turn off
مهم‌ترین قدمه! اگه خاموشش نکنی، ربات عکس‌هایی که بقیه می‌فرستن رو نمی‌بینه.

ب) ربات رو به گروه اضافه کن:

  1. توی گروه: اعضا ← افزودن عضو ← یوزرنیم ربات
  2. ربات رو ادمین کن

ج) تست: توی گروه /start بزن و یک کاروسل بساز.

هر عضو کاروسل خودش رو می‌سازه و همه می‌تونن ورقش بزنن.
۸

انتشار در کانال (اختیاری)

  1. وقتی کاروسل آماده شد، دکمه ⚙️ → 📤 انتشار
  2. یوزرنیم کانال رو بفرست: @mychannel
  3. تمام — کاروسل توی کانال می‌ره و اسم تو دیده نمی‌شه
یادت باشه: ربات باید توی کانال مقصد ادمین باشه.
✅ تمومه! ربات حالا همیشه روشنه و کاروسل‌ها هم ذخیره می‌شن

❓ اگه مشکلی پیش اومد

ربات جواب نمی‌ده

برو Actions و ببین آخرین اجرا سبزه یا نه. اگه قرمز بود، توکن رو چک کن (قدم ۴). اگه سبزه، چند دقیقه صبر کن — گیت‌هاب هر ۵ ساعت ربات رو یک بار ری‌استارت می‌کنه و کمتر از ۱ دقیقه قطعیه.

توی گروه جواب نمی‌ده

Group Privacy رو خاموش نکردی. قدم ۷-الف رو انجام بده، بعد ربات رو از گروه حذف و دوباره اضافه کن.

می‌گه «کاروسل منقضی شده»

یعنی قدم ۳ (Read and write permissions) انجام نشده. انجامش بده و قدم ۵ رو دوباره اجرا کن.

خطای قرمز: No module named PIL

معمولاً خودش حل می‌شه. اگه موند، برو Actions → آخرین اجرا → Run workflow دوباره.

توی ریپو کامیت‌های «chore: state» می‌بینم

کاملاً عادیه — این‌ها ذخیره‌های خودکار خود رباتن تا کاروسل‌ها یادش بمونه. دستشون نزن.

کاروسل با دکمه‌های ◀ ⚙️ ▶ اومد، نه با فلش‌های روی عکس

یعنی تلگرامِ همون دستگاه از قابلیت نیتیو پشتیبانی نکرده و ربات رفته روی حالت جایگزین. تلگرام رو آپدیت کن و دوباره امتحان کن.
