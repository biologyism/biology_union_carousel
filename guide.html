کاروسل‌ها دیگه منقضی نمی‌شن

قبلاً با هر ری‌استارت ربات، دکمه‌های کاروسل‌های قدیمی از کار می‌افتادن. حالا ربات لیست کاروسل‌ها رو توی فایل state.json نگه می‌داره و هر ۹۰ ثانیه اون رو توی همون ریپو ذخیره می‌کنه.

  • ✅ کاروسل هفته پیش هم امروز با ◀ ▶ کار می‌کنه
  • ✅ اگه ربات قطع و وصل بشه، چیزی از دست نمی‌ره
  • ✅ خودکار انجام می‌شه — کاری لازم نیست بکنی
💡 توی ریپو کامیت‌هایی با پیام chore: state [skip ci] می‌بینی — این‌ها همون ذخیره‌های خودکارن. کاملاً عادیه.
⚠️ برای فعال شدنش کافیه کل پوشه رو یک‌جا آپلود کنی — کارت بعدی.
📦

قدم ۱: آپلود یک‌جا (کل پوشه)

لازم نیست فایل‌به‌فایل کاری کنی. یک zip داری که همه‌چیز توش هست:

  1. فایل zip رو دانلود و Extract کن
  2. پوشه رو باز کن و Ctrl + A بزن (همه انتخاب بشن)
  3. برو به ریپو: biologyism/biology_union_carousel
  4. Add file ← Upload files
  5. همه فایل‌ها رو بکش و بنداز توی صفحه
  6. Commit changes
✅ با همین یک آپلود، هم نسخه‌ی اسلایدی جدید نصب می‌شه، هم ذخیره‌سازی دائمی، هم ورک‌فلوی اجرای خودکار.
⚠️ پوشه .github هم باید آپلود بشه، وگرنه ربات اجرا نمی‌شه. اگه ویندوز مخفیش کرده: View ← Hidden items.
💡 فایل‌های هم‌نام (مثل bot.py و main.yml) خودکار جایگزین می‌شن — لازم نیست اول پاکشون کنی.
🔑

قدم ۲: دو تنظیم در گیت‌هاب

الف) اجازه‌ی نوشتن — بدون این، کاروسل‌ها ذخیره نمی‌شن:

  1. Settings → Actions → General
  2. برو پایین صفحه تا Workflow permissions
  3. Read and write permissions رو انتخاب کن
  4. Save

ب) توکن ربات (اگه قبلاً ساختی، رد شو):

  1. Settings → Secrets and variables → Actions
  2. New repository secret
  3. Name: BOT_TOKEN — Secret: توکن BotFather
⚠️ ALLOWED_USER_ID رو خالی بذار تا همه اعضای گروه بتونن استفاده کنن.
▶

چطور استفاده کنم؟

  1. توی چت با ربات (یا توی گروه) بنویس: /start
  2. عکس‌هاش رو یکی‌یکی بفرست (تا ۱۰ تا) 📸
  3. روی «🎬 ساخت کاروسل» بزن
  4. حالا با ◀️ ▶️ بین اسلایدها بچرخ 🎉

بعد از ساخت، این‌ها رو داری:

  • ◀️ ▶️ — ورق زدن اسلایدها (نقطه‌های روی عکس نشون می‌دن کجایی)
  • ⚙️ — منوی گزینه‌ها، شامل:
  • ✏️ کپشن این اسلاید — متن روی همین عکس
  • ➕ عکس — اسلاید جدید
  • ➖ حذف این اسلاید
  • 📤 انتشار — فرستادن به کانال/گروه بدون دیده شدن نامت
  • 🗑 پاک کردن — حذف کل کاروسل
👥

توی گروه — همه بتونن استفاده کنن

۳ کار لازمه:

الف) خاموش کردن Group Privacy:

  1. برو به @BotFather
  2. /mybots → رباتت رو انتخاب کن
  3. Bot Settings ← Group Privacy ← Turn off
⚠️ اگه این کار رو نکنی، ربات عکس‌هایی که بقیه توی گروه می‌فرستن رو نمی‌بینه.

ب) اضافه کردن ربات به گروه:

  1. تنظیمات گروه ← اعضا ← افزودن عضو ← یوزرنیم ربات
  2. ربات رو ادمین کن

ج) تست: توی گروه /start بزن و چند عکس بفرست.

👥 هر عضو گروه /start می‌زنه و کاروسل خودش رو می‌سازه. همه کاروسل‌های ساخته‌شده رو می‌تونن ورق بزنن.
📤

انتشار در کانال (بدون نام من)

  1. وقتی کاروسل آماده شد، دکمه «📤 انتشار» رو بزن
  2. یوزرنیم کانال رو بفرست: @mychannel
    یا آیدی عددی: -1001234567890
  3. تمام! کاروسل توی کانال می‌ره و مردم با ◀ ▶ ورقش می‌زنن
⚠️ ربات باید در کانال/گروه مقصد ادمین باشه، وگرنه ارسال ناموفق می‌شه.
💡 فقط یوزرنیم کانال‌های عمومی کار می‌کنه. برای کانال خصوصی باید آیدی عددی (-100...) بدی.
☑

چک‌لیست

  • ☐ کل پوشه رو یک‌جا آپلود و Commit کردم (شامل .github)
  • ☐ در Settings، «Read and write permissions» رو فعال کردم
  • ☐ توی ریپو فایل state.json ساخته شده (یعنی ذخیره‌سازی کار می‌کنه)
  • ☐ توی Actions علامت سبز ✅ هست
  • ☐ توی چت خصوصی /start + چند عکس + «ساخت کاروسل» تست کردم
  • ☐ Group Privacy خاموشه
  • ☐ ربات توی گروه ادمین شده و جواب می‌ده
  • ☐ انتشار در کانال تست شد

مشکلات رایج

دکمه‌ها کار نمی‌کنن / می‌گه «کاروسل منقضی شده»

با نسخه‌ی جدید دیگه نباید پیش بیاد، چون کاروسل‌ها توی state.json ذخیره می‌شن. اگه باز هم دیدی، یعنی پوشه .github آپلود نشده یا main.yml قدیمیه. در بدترین حالت، عکس‌ها رو دوباره بفرست و یکی جدید بساز — پیام قبلی توی تلگرام پاک نمی‌شه.

عکس عوض می‌شه ولی پیام جدید هم میاد

این‌طبیعیه: پیام‌های «✅ ذخیره شد» جدا فرستاده می‌شن. فقط خودِ کاروسل در یک پیام می‌مونه.

کپشن نمی‌شینه

مطمئن شو بعد از زدن «✏️ کپشن این اسلاید» متن رو به‌صورت پیام فرستادی. کپشن هر اسلاید جداست.

توی گروه جواب نمی‌ده

۹۰٪ مواقع Group Privacy خاموش نشده. بعد از خاموش کردن، ربات رو از گروه حذف و دوباره اضافه کن.

Actions قرمز شد ❌

توکن اشتباهه. Settings ← Secrets and variables ← Actions ← BOT_TOKEN رو درست کن.
