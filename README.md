# 🤖 ربات کاروسل تلگرام

رباتی ساده که تا **۱۰ عکس** ازت می‌گیره و اون‌ها رو به یک **کاروسل اسلایدی واقعی** تبدیل می‌کنه:
یک پیام واحد که با دکمه‌های **◀️ ▶️** عکسش عوض می‌شه و نقطه‌های پایین موقعیت اسلاید رو نشون می‌دن.

> 📄 راهنمای تصویری و ساده: فایل [`guide.html`](guide.html) را در مرورگر باز کنید.

## ✨ قابلیت‌ها

| قابلیت | توضیح |

| 🎠 کاروسل اسلایدی | ۱ تا ۱۰ عکس در **یک پیام**، جابه‌جایی با ◀️ ▶️ بدون ارسال پیام جدید |
| 🖼 فلش و نقطه روی عکس | فلش‌های ◀ ▶ روی لبه‌های عکس و نقطه‌های نشانگر پایین عکس کشیده می‌شوند (Pillow) |

## ♾ کاروسل‌های دائمی (ذخیره‌سازی)

کاروسل‌ها در فایل `state.json` نگه داشته می‌شوند و ربات هر ۹۰ ثانیه تغییرات را ذخیره می‌کند:
`STATE_PERSIST=git` → ذخیره در ریپو (برای GitHub Actions) | `file` → فقط روی دیسک (VPS / Docker).

- بعد از هر ری‌استارت، دکمه‌های کاروسل‌های قبلی همچنان کار می‌کنند.
- بیش از ۵۰۰ کاروسل نگه داشته نمی‌شود (قدیمی‌ترها پاک می‌شوند).
- در حالت `git`، ورک‌فلو با `paths-ignore: state.json` از حلقه‌ی بی‌پایان جلوگیری می‌کند.

## 🚀 راه‌اندازی قدم‌به‌قدم

### ۱. ساخت ربات و گرفتن توکن
1. توی تلگرام برو به [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزن، اسم و یوزرنیم ربات رو انتخاب کن
3. **توکن** رو کپی کن (یه چیزی مثل `123456:ABC-DEF...`)

### ۲. ساخت ریپوی خصوصی در گیت‌هاب
1. توی گیت‌هاب یه ریپو با حالت **Private** بساز
2. همه فایل‌های این پروژه رو توش آپلود کن (push کن)

### ۳. تنظیم Secrets در گیت‌هاب
توی ریپو: **Settings → Secrets and variables → Actions → New repository secret**

| نام Secret | مقدار |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `FORWARD_CHAT_ID` | (اختیاری) آیدی کانال پیش‌فرض، مثل `-1001234567890` |
| `ALLOWED_USER_ID` | (اختیاری) آیدی عددی — **برای استفاده گروهی خالی بگذارید** تا همه اعضا بتوانند استفاده کنند |

> برای گرفتن آیدی عددی خودت، به [@userinfobot](https://t.me/userinfobot) پیام بده.

### ۴. اجرا — دو روش داری

#### روش A: مستقیم روی GitHub Actions (سریع، ولی با قطعی)
فایل `.github/workflows/main.yml` از قبل آماده‌ست.
کافیه Secrets رو ست کنی و یه push بزنی — ربات روی گیت‌هاب اجرا می‌شه.

⚠️ **محدودیت مهم:** گیت‌هاب اکشنز هر اجرا رو بعد از حداکثر ۶ ساعت قطع می‌کنه.
این ورک‌فلو هر ۵ ساعت دوباره شروع می‌شه، ولی ممکنه چند دقیقه آفلاین باشه.
برای استفاده شخصی کافیه، ولی برای همیشه‌آنلاین بودن روش B بهتره.

#### روش B: روی سرور مجازی VPS با Docker (پیشنهادی، ۲۴/۷) ✅
1. یه VPS بگیر (مثلاً از Hetzner، DigitalOcean، یا هر ارائه‌دهنده‌ای) و روش SSH رو فعال کن
2. روی سرور داکر نصب کن:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. روی سرور این پروژه رو clone کن و فایل `.env` بساز:
   ```bash
   git clone <آدرس ریپوی خصوصی‌ت>
   cd telegram-carousel-bot
   cp .env.example .env
   nano .env   # BOT_TOKEN رو پر کن
   ```
4. اجرا:
   ```bash
   docker compose up -d --build
   ```
5. (اختیاری) برای دیپلوی خودکار روی VPS، فایل `.github/workflows/main.yml` را با یک ورک‌فلو SSH جایگزین کن (توضیح در راهنمای HTML).

## 📤 فوروارد مخفی چطور کار می‌کنه؟

دو راه داری:

**راه ۱ — از داخل ربات (پیشنهادی):**
بعد از ساخت کاروسل روی «📤 فوروارد مخفی» بزن و مقصد رو بفرست (`@mychannel` یا آیدی عددی).
ربات کاروسل رو مستقیم به مقصد می‌فرسته، پس **نام شما هیچ‌جا دیده نمی‌شه**.

> ⚠️ ربات باید در کانال/گروه مقصد **ادمین** باشه و اجازه ارسال عکس داشته باشه.

**راه ۲ — فوروارد دستی در تلگرام:**
اگه خودت کاروسل رو فوروارد کنی، توی پنجره فوروارد تلگرام گزینه **«Hide my name / مخفی کردن نام من»** رو فعال کن تا نامت دیده نشه.

## 🖥 اجرای محلی (برای تست)

```bash
pip install -r requirements.txt
cp .env.example .env   # توکن رو پر کن
python bot.py
```

## ❓ عیب‌یابی

- **ربات جواب نمی‌ده؟** مطمئن شو `BOT_TOKEN` در Secrets درست ست شده و ورک‌فلو سبز (success) شده.
- **فوروارد خطا می‌ده؟** ربات رو در کانال/گروه مقصد ادمین کن.
- **کپشن ویرایش نمی‌شه؟** تلگرام فقط کپشن عکس اول آلبوم رو اجازه ویرایش می‌ده؛ اگه آلبوم قدیمی باشه، حذفش کن و از اول بساز.
