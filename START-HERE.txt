====================================================
        ربات کاروسل تلگرام — از اینجا شروع کن
====================================================

این پوشه همه‌چیز رو داره. فقط ۵ قدم:

----------------------------------------------------
قدم ۱ — اکسترکت
----------------------------------------------------
فایل zip رو دانلود کن، راست‌کلیک → Extract All
حالا یه پوشه داری که همین فایل‌ها توش هست.


----------------------------------------------------
قدم ۲ — آپلود روی گیت‌هاب (یک‌جا)
----------------------------------------------------
1) برو به ریپوت:
   github.com/biologyism/biology_union_carousel

2) دکمه  Add file  →  Upload files

3) پوشه رو باز کن، Ctrl + A  بزن (همه انتخاب بشن)
   بعد همه رو بکش و بنداز توی صفحه گیت‌هاب

4) پایین صفحه  Commit changes  رو بزن

نکته: پوشه .github هم باید آپلود بشه.
      (اگه ویندوز مخفیش کرده: View → Hidden items)


----------------------------------------------------
قدم ۳ — دو تنظیم در Settings (مهم!)
----------------------------------------------------

۳-الف) اجازه‌ی نوشتن (برای ذخیره‌ی دائمی کاروسل‌ها)
   Settings → Actions → General
   پایین صفحه → Workflow permissions
   گزینه «Read and write permissions» رو انتخاب کن
   → Save

    بدون این، ربات کار می‌کنه ولی بعد از هر ری‌استارت
    کاروسل‌های قبلی از کار می‌افتن.

۳-ب) توکن (اگه قبلاً ساختی، رد شو)
   Settings → Secrets and variables → Actions
   → New repository secret

      Name:   BOT_TOKEN
      Secret: توکنی که @BotFather داده

⚠️ ALLOWED_USER_ID رو خالی بذار تا همه اعضای گروه بتونن استفاده کنن.


----------------------------------------------------
قدم ۴ — روشن کردن
----------------------------------------------------
تب Actions →  Run Carousel Bot  →  Run workflow
تا سبز ✅ بشه صبر کن (۱-۲ دقیقه)


----------------------------------------------------
قدم ۵ — تست
----------------------------------------------------
تو تلگرام برو به ربات، بزن:  /start
چند عکس بفرست (یکی‌یکی) → «🎬 ساخت کاروسل»
حالا با ◀️ ▶️ ورق بزن 🎉

----------------------------------------------------
نکات مهم
----------------------------------------------------
• ربات تقریباً همیشه روشنه. هر ۵ ساعت خودش ری‌استارت
  می‌شه و کمتر از ۱ دقیقه قطعیه.

• کاروسل‌ها توی فایل state.json ذخیره می‌شن، پس بعد از
  ری‌استارت هم دکمه‌هاشون کار می‌کنه.

• توی ریپو کامیت‌هایی با پیام «chore: state [skip ci]»
  می‌بینی. اینا ذخیره‌های خودکار خود رباتن. عادیه.

• برای گروه: توی @BotFather دستور /mybots → ربات →
  Bot Settings → Group Privacy → Turn off
  بعد ربات رو به گروه اضافه و ادمین کن.

• اگه فایل docker_compose.yml قدیمی توی ریپوت مونده،
  مشکلی ایجاد نمی‌کنه. می‌تونی پاکش کنی.
